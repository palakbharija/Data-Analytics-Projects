# ApexPlanet Internship - Task 4

## Data Storytelling & Statistical Validation

This project presents a business-focused analysis of customer sales data. The main objective was to understand customer behaviour, identify high-value customers and validate an important business observation using statistical testing.

## Key KPIs

- Total Sales: ₹139.40M
- Total Orders: 992
- Total Customers: 947
- Average Order Value: ₹140.52K
- Average Customer Spend: ₹147.20K

## Deep-Dive Analysis

The analysis focuses on customer value segmentation.

Customers were divided into three groups:

- High Value
- Medium Value
- Low Value

The segmentation helped compare customer contribution and understand which groups generate the most sales.

## Key Findings

- High Value customers contribute the highest sales.
- Medium Value customers make up the largest customer group.
- Electronics is the leading category among High Value customers.
- Bengaluru records the highest High Value customer sales in the analysis.
- March has the highest monthly sales, while September has the lowest.

## Hypothesis Testing

A Welch independent-samples t-test was used to compare the average sales value of Electronics orders with non-Electronics orders.

The p-value obtained was 0.414.

Since the p-value is greater than 0.05, the result is not statistically significant. Therefore, the null hypothesis was not rejected.

This means that although Electronics has the highest overall sales contribution, its average order sales value is not statistically different from non-Electronics orders.

## Business Recommendations

- Focus on retaining High Value customers through targeted offers and loyalty strategies.
- Use cross-selling and upselling to increase spending among Medium Value customers.
- Use category and city-level insights for more targeted campaigns.
- Monitor monthly sales trends to plan promotions and inventory better.
